# Data Sources

## Aerial Imagery
- NAIP (National Agriculture Imagery Program)
- Accessed via Microsoft Planetary Computer STAC
- Resolution: ~0.6–1m
- Coverage: United States

## Reference Buildings
- OpenStreetMap building footprints
- Accessed using OSMnx (Overpass API)

## Notes
- No imagery is stored in this repository
- Users can change AOI and imagery year directly in the notebook
